# ZenithEdu OS™ · Commercial Institute & Academy Management Suite

> **Enterprise Multi-Tenant Coaching Institute Operating System**  
> Complete B2B solution for test-prep academies (JEE, NEET, CBSE, Foundation). Includes Student SIS, Biometric Attendance, GST Fee Billing, AI Question Paper Studio, Meta Cloud WhatsApp Automation, Timetable Clash Detector, Vertical PVC ID Badges, and B2B SaaS Licensing.

---

## 🌟 Key Modules & Capabilities

1. **Student Information System (SIS)**
   - Complete enrollment directory, roll numbering, batch segmentation (`Class 12 JEE Elite`, `NEET Super 30`, `CBSE 12`, `Foundation 10`).
   - Dynamic search, batch filtering, and 1-click CSV muster roll export.
   - 1-Click WhatsApp messaging for parents on every student row.

2. **Daily Attendance Muster Roll**
   - Interactive biometric roster with instant `P` (Present), `L` (Late), and `A` (Absent) toggles.
   - Real-time attendance counters and automatic absentee parent WhatsApp alert integration.

3. **Fees & Billing Console**
   - Outstanding recovery ledger and installment tracking.
   - 1-Click Razorpay Smart Checkout UPI modal with dynamic QR code (GPay, PhonePe, Paytm).
   - Official B2B GST Tax Receipt generation (`REC-2026-xxx`) with automated 18% CGST/SGST separation.

4. **✨ AI Question Paper & Mock Test Studio**
   - National standard test paper generator for **JEE Main & Advanced, NEET-UG, CBSE 10/12**.
   - LaTeX-rendered mathematical formulas and diagrams with +4 / -1 marking scheme.
   - Toggleable step-by-step solutions and answer keys.
   - Watermarked official printable examination paper PDF layout (`paperPrintModal`).

5. **📲 Automated WhatsApp Broadcast & Live 2-Way CRM Hub**
   - **Meta Cloud Business API** Tier 3 integration (100k msgs/day).
   - **Campaign Studio:** Bulk dispatch to 142 fee defaulters, 60 absentees, mock test rank alerts with live progress simulation.
   - **Live 2-Way WhatsApp CRM Inbox:** Full 3-column WhatsApp Web interface inside the OS with message composer, canned response chips, simulated parent replies with double blue checkmarks (`✓✓`).
   - **Real WhatsApp Deep-Linking:** Direct click-to-chat sandbox (`https://api.whatsapp.com/send?phone=...`) to test real messages on your own phone.

6. **🗓️ Weekly Timetable Matrix & Lecture Clash Detector**
   - 6-Day schedule matrix (Mon–Sat) across classrooms and batches.
   - Real-time conflict/clash detection for faculty double-booking.

7. **📇 Digital Student ID Card & PVC Badge Studio**
   - Vertical CR-80 PVC identity pass format with dark obsidian gradient, gold accents, barcode, and dynamic QR verification token.
   - Printable thermal layout and instant WhatsApp digital pass dispatch.

8. **🎓 Cumulative Academic Progress Scorecard**
   - Formal report card modal with subject breakdown (Physics, Chemistry, Maths), batch percentile, AIR rankings, teacher remarks, and authorized digital signatures.

9. **⚡ Spotlight Command Palette (`Ctrl + K`)**
   - Global keyboard launcher for instant navigation, quick student search, and fast administrative actions.

10. **💼 Commercial B2B Sales Kit & Proposal Generator**
    - Interactive ROI & License Fee Calculator (Student capacity, campus branches, fee tiers).
    - Formal B2B Enterprise Quotation document ready for direct PDF printing.

11. **📱 Progressive Web App (PWA)**
    - Installable as a standalone Windows / macOS desktop application via `manifest.json` and `sw.js`.

## 🚀 Quick Start / Local Deployment

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Zaidkhan7024/zenithedu-os.git
   cd zenithedu-os
   ```

2. **Serve locally using Python or any static web server:**
   ```bash
   python -m http.server 8085
   ```

3. **Open in browser:**
   ```
   http://localhost:8085
   ```
